# Research findings

Findings filed here carry a status and the identities of their sources. A finding is not an architectural decision. ChatGPT turns a consequential finding into an amendment under [`docs/decisions/`](../decisions/) or [`docs/tasks/`](../tasks/). Perplexity Computer is the role that supplies research. Cursor does not treat a file in this directory as permission to change production behavior.

No finding is filed by T01. Private hardware samples, identifiers, commercial information, and unreleased tournament material do not belong here. A public task references an approved manifest or a public summary.
